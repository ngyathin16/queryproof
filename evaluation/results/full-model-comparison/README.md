# Exploratory comparison

These 144 real local-model trials were collected while implementation continued. The Python process cached the analysis module at startup while worker code changed on disk. This directory is retained as development evidence, including failed proposals. It is **not** the final comparison against a frozen implementation revision. The raw summary's `complete_acceptance_comparison` flag means all 144 scheduled trials ran; it does not establish every acceptance gate or source-version stability.

Use the later revision-pinned comparison identified in `docs/VERIFICATION.md` for the reproducible implementation results. Do not omit these earlier failures or characterize inspected cases as unseen.
